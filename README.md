# Abdul Bari DSA in Java: Practice

My practice code for the NextLeap course **Data Structures & Algorithms in Java** by Abdul Bari.
43 modules, 402 lectures. One package per module, in the same order as the course.

## How to use

1. Open this folder in IntelliJ (File > Open > `abdul-bari-dsa`).
2. Find the module's package inside `src/`, for example `src/m08_arrays_intro_operations`.
3. Right-click the package > New > Java Class. IntelliJ adds the `package` line on top for you.
4. Give every class its own `main()`, so each program runs on its own.
5. When a lecture is done, tick it in that module's `README.md` (`- [ ]` becomes `- [x]`).

Quizzes are not in the checklists. Lecture names are copied as they appear on the course page, so they match the course sidebar.
